# Changelog

## v0.1.0 — first public prototype

- Redesigned Kickoff as a responsive football news and fan site with separate Home, News, Matches, Standings, Teams, and Players pages.
- Added Simplified Chinese, Traditional Chinese, and English, plus light, dark, and system appearance options.
- Added local team follows, site search, news and result filters, match summaries, standings, and player rankings.
- Added a real football photograph with attribution and license details. Other visual elements are built with CSS.
- Added browser interaction tests for navigation, filters, language, appearance, and team selection.

This release uses sample editorial, match, standings, player, and discussion data. Live data feeds, accounts, comments, and publishing workflows are planned for later versions.
